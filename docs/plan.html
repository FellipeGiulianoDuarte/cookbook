Why the grind converter must change

Every published converter (Honest Coffee Guide, Beean, Basic Barista, BrewMark) is linear. But the two families of "microns per click" numbers differ by about 3×: manufacturers publish burr-gap travel (1Zpresso J: 25 µm/click; Kingrinder K6: 16 µm/click), while Honest Coffee Guide publishes an estimated particle-size range spread evenly over the dial (1Zpresso J: 9 µm/click; K6: 8.4 µm/click). If v2 divides a target micron value by the manufacturer's travel figure, a Kingrinder K6 user gets half the correct clicks. The fix in Phase 1: every grinder carries its official click band per brew method (for example Comandante V60 18–35 clicks, Kingrinder K6 pour-over 100 clicks, 1Zpresso K-Ultra 80–90 clicks). The recipe asks for a position inside the method band ("fine end of V60"), and the app interpolates inside that grinder's own band. Microns appear only as a secondary label from the Honest Coffee Guide scale.

What v2 is

A state machine, not a page

Method → recipe → grinder → dose → bean → options → summary → brew (timer) → done. Every choice changes the numbers downstream. The URL carries the choices, so a recipe is a shareable link.

Sourced data

Every number in data/ has a source.url, a year and a confidence flag (official / transcription / community). Disagreements between sources are stored, not hidden.

Kitchen-proof

Big targets, screen stays awake, beeps at each pour, one Pause button during the brew, works offline after the first visit.

3D as the hero

One WebGL canvas. The V60 and the AeroPress are procedural meshes with glass and liquid shaders. The grinder dial turns to the computed click count. The brew step animates the pours in time with the clock.

Two methods first

V60 and AeroPress at launch. Chemex, French press, Kalita, moka and espresso are data additions later; the schema supports them from day one.

Ships in slices

Phase 0 deploys an empty app. Phase 1 makes the data correct. Phase 2 makes it usable. Phase 3 makes it kitchen-ready. Phase 4 makes it beautiful. Phase 5 makes it shareable.

3. Grind conversion model

Input: the recipe's grind = { method: 'v60', pos: 0.25 } (0 = finest end of that method's band, 1 = coarsest). Grinder record: bands.v60.official = [18, 35]. Output: 18 + 0.25 × (35 − 18) = 22.25 → 22 clicks, tolerance from the grinder's zero tolerance, rendered in the grinder's notation. If a grinder has no official band for the method, use its community band and flag it. If it has neither, fall back to the Honest Coffee Guide linear model (µm = min + (max − min) × tick / N) with the method's Honest Coffee Guide micron range, and flag "estimated". Recipes that only give a texture word ("medium-fine") map to a position by a fixed table (fine end 0.2, middle 0.5, coarse end 0.8). Recipes with measured microns (Onyx 550 µm) map by the Honest Coffee Guide V60 range 400–700 → position 0.5.

Stepless grinders (Niche, DF64, Eureka, Varia) render a mark on a continuous ring plus the text "turn N marks from your zero". Dual-resolution grinders (Encore ESP 1–20 fine / 21–40 coarse, Fellow Opus outer + inner ring, Sette macro + micro) store two segments in bands. Labelled dials (Wilfa Svart) store label anchors, not numbers.

Risks

Phase 4 variance

Liquid shaders and mobile GPU budgets are the one place estimates slip. Mitigation: Phases 0–3 ship a complete app first; the 3D slot has a static fallback from day one; PerformanceMonitor drops transmission (glass refraction renders the scene twice) before tuning visuals.

drei 11 alpha and WebGPU churn

drei 11 (alpha, 2026-09-05) splits materials into legacy/WebGPU and has not ported MeshTransmissionMaterial. Pin drei ^10.7, three 0.185, R3F ^9.7. Revisit when drei 11 is stable; budget one day.

Grinder data is a band, not a point

Manufacturers state zero-point tolerances of ±2 to ±10 clicks (1Zpresso J-Max: ±10). Two units of the same model can differ by 5–7 marks (Niche). The app must always show a tolerance and offer the per-user offset. Never present one integer as "the" setting.

Recipe numbers from video transcriptions

Hoffmann's numbers come from three matching written transcriptions (YouTube does not render for fetch). Kasuya's 5th pour is at 2:40, 2:45 or 3:00 depending on source. Store the disagreement in source.notes and show the primary source's value.

iOS has no web haptics

The Vibration API is not in Safari. Timer feedback on iPhone is audio and visual only. Android gets vibration as a bonus.

Vercel Hobby limits

Personal repo only, non-commercial, 100 GB/month transfer, 1 concurrent build, analytics pause at 50k events/month. All fine for a personal app.

Fresh major versions

TypeScript 7 (Go compiler, July 2026), Vitest 5.0.0 (4 days old), pnpm 12. Pin exact versions; if Vitest 5 misbehaves, use 4.1.

import { z } from 'zod';

export const Source = z.object({
  url: z.string().url(), title: z.string(), year: z.number().int().optional(),
  kind: z.enum(['primary', 'transcription', 'community']),
  notes: z.string().optional(),          // where sources disagree, say so here
});

// A step's water is a function of dose so scaling is data, not code.
export const Step = z.object({
  at: z.number().nonnegative(),                          // seconds from start
  until: z.number().nonnegative().optional(),            // pour end, if timed
  action: z.enum(['bloom','pour','stir','swirl','wait','cap','flip','press','dilute','drawdown','serve']),
  water: z.union([
    z.object({ times: z.number() }),                     // bloom: 2 × dose
    z.object({ share: z.number() }),                     // pour to 60 % of total
    z.object({ grams: z.number() }),                     // fixed grams (Kasuya 60 g pulses)
  ]).optional(),                                         // cumulative target
  text: z.record(z.enum(['pt-BR','en']), z.string()),
  cue: z.string().optional(),                            // 3D/GSAP label
});

export const Recipe = z.object({
  id: z.string(), method: Method, name: z.string(), author: z.string(), year: z.number().optional(),
  dose: z.object({ default: z.number(), min: z.number(), max: z.number() }),
  ratio: z.number(),                                     // water = dose × ratio
  grind: z.object({ band: Method, pos: z.number().min(0).max(1), microns: z.number().optional(), label: z.string() }),
  temperature: z.object({ default: z.number(), byRoast: z.record(z.string(), z.number()).optional(), note: z.string().optional() }),
  steps: z.array(Step), totalSeconds: z.number(),
  options: z.record(z.string(), z.unknown()).optional(), // aeropress: orientation, filter, model
  scaling: z.enum(['linear', 'fixed', 'dose-multiples']),
  source: Source, alsoSee: z.array(Source).optional(),
});

export const Grinder = z.object({
  id: z.string(), brand: z.string(), model: z.string(),
  kind: z.enum(['hand', 'electric']),
  adjustment: z.enum(['stepped', 'stepless', 'labelled', 'dual']),
  notation: z.enum(['clicks', 'rot.num.tick', 'dial', 'dial.sub', 'marks', 'labels']),

lib/engine/grind.ts — band interpolation, not microns ÷ travel

export function gridToSetting(g: Grinder, method: Method, pos: number, offset = 0): Setting {
  const band = g.bands[method];
  let lo: number, hi: number, basis: 'official' | 'community' | 'estimated';
  if (band?.official)        { [lo, hi] = band.official;  basis = 'official'; }
  else if (band?.community) { [lo, hi] = band.community; basis = 'community'; }
  else if (g.hcg) {          // Honest Coffee Guide linear model as last resort
    const [uMin, uMax] = MICRONS[method];                     // e.g. v60: [400, 700]
    const toTick = (u: number) => (u - g.hcg.micronRange[0]) / (g.hcg.micronRange[1] - g.hcg.micronRange[0]) * g.hcg.ticks;
    lo = toTick(uMin); hi = toTick(uMax); basis = 'estimated';
  } else return { kind: 'unknown', basis: 'estimated' };

  const raw = lo + pos * (hi - lo) + offset;
  const value = g.adjustment === 'stepless' ? round(raw, 0.5) : Math.round(raw);
  return {
    kind: 'ok', value, basis,
    tolerance: g.zero.toleranceClicks,
    band: [lo, hi],
    outOfRange: value < g.range[0] || value > g.range[1],
    unsafe: g.zero.unsafeBelow !== undefined && value < g.zero.unsafeBelow,
    text: format(g, value),               // "26 clicks" · "2.6.0 (2 turns + 6 numbers)" · "dial 5.1" · "mark 42 from your zero"
  };
}

  return r.steps.map(s => {
    if (s.water) {
      if ('times' in s.water) cum = Math.round(dose * s.water.times);          // Hoffmann bloom 2×
      if ('share' in s.water) cum = Math.round(total * s.water.share);        // Hoffmann 60 %
      if ('grams' in s.water) cum += r.scaling === 'dose-multiples'            // Kasuya 60 g at 20 g → 3× dose
        ? Math.round(s.water.grams / r.dose.default * dose) : s.water.grams;
    }
    return { ...s, cumulative: Math.min(cum, total), total };
  });
}

});
